이 스킬 디렉토리 기준 `../grilling/SKILL.md` 를 읽고 그대로 진행한다. 아래만 다르다.

## 세션 끝: ADR 후보

grilling 이 끝나면 (프런티어가 비고 사용자가 공통 이해를 확인하면) 확정된 결정을 [`ADR-FORMAT.md`](ADR-FORMAT.md) 의 세 조건으로 거른다. 세 조건 모두에 근거를 댈 수 있는 결정만 후보로 보여준다.

```
ADR 후보 N건
1. <결정 한 줄>
   되돌리기 어려움: <근거> / 맥락 없이 의아함: <근거> / 트레이드오프: <버린 대안>
2. ...
남길 번호를 골라 달라.
```

사용자가 고른 것만 쓴다. 고른 것이 없으면 아무 파일도 만들지 않는다.

## 작성

`ADR-FORMAT.md` 를 따라 쓴다. 맥락, 이유, 버린 대안은 세션 대화에서 가져온다: 사용자가 말한 이유를 쓰고, 대화에 없는 이유는 쓰지 않는다. 끝나면 쓴 파일 경로를 보고한다.
